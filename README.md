# Hi, I'm Krishnasai Rollamadugu

**Test Automation Architect (11+ years)** researching **trust and measurement in AI-driven software testing**.

When AI *writes*, *heals*, and *judges* our tests, a green result is no longer automatically trustworthy. I build methods and metrics to tell which AI testing verdicts can actually be believed.

---

### Featured research project — TrustLab

[**TrustLab**](https://github.com/rollamadugu/trustlab) measures the **False-Confidence Gap** — the distance between how often tests *appear* to pass and how often they are *actually* sound — across three AI testing modalities, grounded in **real mutation testing**.

![False-Confidence Gap by AI testing modality](https://raw.githubusercontent.com/rollamadugu/trustlab/main/assets/false_confidence_gap.png)

Read the write-up: [**Can you trust a green test written by AI? I measured it.**](https://dev.to/rollamadugu/can-you-trust-a-green-test-written-by-ai-i-measured-it-2bk6)
